# Medi-Tau 💊

A React-based medicine search application using the FDA Drug Label API.

## 🚀 Live Demo

**[medi-tau-five.vercel.app](https://medi-tau-five.vercel.app/)**

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* FDA Drug Label API

## ✨ Features

* Search for medicines
* Debounced API search
* Display medicine brand names
* Select a medicine from the search results
* Handles API errors

## 💻 Run Locally

```bash
npm install
npm run dev
```
